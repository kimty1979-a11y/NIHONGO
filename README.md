# 日本語 데일리 PWA v0.1.1 — 문장 문제 수정

## 바뀐 점

- 문장 뜻 고르기: 일본어 문장의 한국어 번역만 선택지에 표시합니다.
- ‘何名様ですか？’의 정답은 ‘몇 분이세요?’입니다.
- 예약 여부, 봉투 필요 여부, 이름 질문도 같은 기준으로 수정했습니다.
- 정답/오답 해설도 질문의 뜻을 보여 줍니다. 대답 예문과 혼동하지 않습니다.
- 말하기의 대답 문제는 ‘일행 4명’, ‘예약 없이 방문’, ‘봉투 불필요’, ‘예약자 김’ 등 조건을 먼저 제시합니다.
- 따라 말하기는 들은 문장 자체를 말하는 방식입니다.
- 업데이트된 파일을 적용하도록 오프라인 캐시 버전을 올렸습니다.
- 기존 저장 키를 유지해 같은 주소의 학습 기록을 이어갑니다. 이미 기록된 이전 문제의 점수는 소급 수정하지 않습니다.

## 기존 앱 업데이트

1. 기존 앱 설정에서 ‘기록 백업’을 눌러 백업 파일을 받아 둡니다.
2. 이 ZIP을 PC에서 압축 해제합니다.
3. 기존 일본어 앱 GitHub 저장소에서 Add file → Upload files를 누릅니다.
4. 압축 해제 폴더 안 파일을 모두 업로드해 같은 이름의 파일을 교체하고 Commit changes를 누릅니다. ZIP 자체를 올리지 마세요.
5. 기존 Pages 설정과 주소는 유지합니다. FIT LOG 저장소에는 올리지 마세요.
6. GitHub 배포가 끝나면 같은 주소를 Safari에서 열고 새로고침합니다.
7. 앱을 완전히 닫았다가 다시 열고 ‘설정’ 하단에 v0.1.1이 표시되는지 확인합니다.
8. 구버전이 계속 보이면 인터넷에 연결된 상태에서 Safari 새로고침 후 한 번 더 닫았다 엽니다. 학습 기록을 잃을 수 있는 사이트 데이터 삭제는 하지 마세요.

## 동작 범위

- 뜻 고르기 문제는 무음/듣기 모드에서 동일한 번역 정답을 사용합니다.
- 말하기 모드는 원문 따라 말하기 또는 조건에 맞게 대답하기입니다.
- 음성 인식/읽어주기는 기기 및 브라우저 지원과 권한, 네트워크에 따라 달라집니다.
- 기록은 현재 기기와 브라우저에 보관됩니다. 자동 동기화 기능은 없습니다.
- 기존의 통역·필기 인식·햅틱 제외 방침은 유지합니다.
