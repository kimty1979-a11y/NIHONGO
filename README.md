# 日本語 데일리 PWA v0.1

FIT LOG와 동일하게 GitHub Pages에 업로드하여 아이폰 홈 화면에서 사용하는 일본어 학습 앱입니다.
별도 빌드·설치·API 키·유료 번역 서비스가 필요하지 않습니다.

## GitHub에 올리기

1. 이 ZIP을 PC에서 압축 해제합니다. ZIP 자체를 업로드하지 마세요.
2. GitHub에서 일본어 앱 전용 새 저장소를 만듭니다. 예: nihongo-daily
   - FIT LOG 저장소에는 올리지 마세요. 기존 FIT LOG 파일을 덮어쓰면 안 됩니다.
   - 무료 GitHub Pages 사용 시 Public 저장소를 선택하면 소스와 학습 자료가 공개됩니다.
   - 개인 학습 기록은 브라우저에 저장되며 저장소에 올라가지 않습니다.
3. 저장소의 Add file → Upload files에서 압축 해제한 폴더 안의 파일을 모두 업로드하고 Commit changes를 누릅니다.
   - 저장소 첫 화면에 index.html, app.js, style.css 등이 바로 보여야 합니다.
   - 상위 폴더째 올리지 말고 그 안의 파일을 올리세요.
4. Settings → Pages → Build and deployment에서 다음을 선택합니다.
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
   - Save
5. 배포가 끝나면 같은 Pages 화면의 실제 사이트 주소를 엽니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 아이폰 홈 화면에 설치

1. 위에서 확인한 GitHub Pages 주소를 아이폰 Safari로 엽니다.
2. 공유 → 홈 화면에 추가 → 추가를 누릅니다.
3. 처음 한 번은 인터넷이 연결된 상태에서 엽니다.
4. 말하기 기능을 처음 사용할 때 마이크 권한을 허용합니다.

## v0.1 구성

- 음식/음료 단어 6개, 여행/이동 단어 6개, 생활 표현 6개
- 그림(이모지) 보고 일본어 단어 고르기 / 마이크로 말하기
- 무음 / 듣기 / 말하기 모드
- 표현 듣고 따라 말하기 / 질문에 대답하기
- 정답·오답 및 완료 효과음, 무음 모드에서 자동 음소거
- 반복 복습, 하루 목표, 학습 달력과 연속 학습일
- 한국어 발음 표시/숨기기, 기록 백업/가져오기
- 확정한 후지산·붉은 해·日本語 아이콘

## 저장과 업데이트

- 기록은 현재 주소의 브라우저 저장 공간에 보관됩니다. 기기 간 자동 동기화는 없습니다.
- 기존 Sites 주소에서 공부한 기록은 자동 이동하지 않습니다. 기존 앱 설정에서 기록 백업 후 새 앱에서 가져오면 됩니다.
- 같은 GitHub 계정의 다른 Pages 앱과는 고유 저장 키로 구분합니다.
- Safari 데이터 삭제 전 설정에서 기록 백업을 권장합니다.
- 다음 업데이트는 같은 저장소와 주소에서 파일 교체로 진행합니다. 교체 전 기록을 백업하세요.
- 앱을 닫고 다시 열어 새 파일을 불러오세요. 향후 서비스 워커를 변경할 때 CACHE 버전도 올려야 합니다.

## 동작 범위

- 학습 시작·정답·오답·완료·기록 저장은 기존 버전에서 브라우저로 점검했습니다.
- GitHub 저장소 업로드 및 실제 GitHub Pages 배포는 사용자가 위 절차로 진행해야 합니다.
- 서비스 워커가 한 번 설치되고 나면 기본 무음 학습은 오프라인에서도 사용할 수 있도록 구성했습니다.
- 음성 인식은 브라우저 지원, 마이크 권한 및 네트워크에 따라 달라집니다. 실제 아이폰에서 확인이 필요합니다.
- 읽어주기는 기기/브라우저의 일본어 음성을 사용합니다. 음성을 사용할 수 없다면 무음으로 학습할 수 있습니다.
- 음성은 녹음문과 정해진 답변을 비교합니다. 정밀 발음 평가나 모든 자유 답변의 의미 판정은 제공하지 않습니다.
- 통역, 필기 인식, 햅틱, 유료 API 연결은 포함하지 않습니다.
